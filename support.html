If you're reporting a bug

Bug reports get fixed faster when they're easy to reproduce. The list below is what I'd ask for anyway — paste these into the email if you can.

macOS version
e.g. macOS 14.5 Sonoma. Find it at Apple menu → About This Mac.
MenuCalendar version
Open MenuCalendar and choose MenuCalendar → About, or look in Finder's "Get Info" on the app.
Which calendar source
iCloud, Exchange, Google, or a mix. If it's Google, note which account if you've connected more than one.
Steps to reproduce
"I opened the popover, clicked next month, then ___" — even rough steps help a lot. If you can't reproduce it reliably, say that too.
What you expected vs. what happened
Even one sentence each is fine. "Expected: today highlighted. Got: empty grid."
Screenshot if it's visual
⌘⇧4 grabs a region. Layout and theme bugs are much easier to spot from a picture than a description.
Console log, if there's a crash
Open Console.app, search for MenuCalendar, and copy anything that looks like an error or stack trace.

Before you email

A couple of things worth checking — they fix a surprising number of issues:

  • Quit and reopen MenuCalendar. Right-click the menu bar icon → Quit, then relaunch from the Applications folder.
  • Check calendar permissions. System Settings → Privacy & Security → Calendars. MenuCalendar should be toggled on. If you previously denied it, you'll need to toggle it on here — macOS won't ask again.
  • For Google issues: open MenuCalendar's Settings → Calendars tab, disconnect the Google account, and reconnect. This forces a fresh OAuth handshake.
  • Check the changelog in case the issue is a known limitation rather than a bug.
