1.0.0
June 4, 2026
Current

First public release.

Free download, Developer ID signed and notarised. Every feature listed below is in this build — go grab it.

Added
  • Menu bar status item with a date glyph that updates at midnight.
  • Popover with a 6×7 month grid, today highlighted, dots on event days.
  • Agenda list for the selected day; selecting "Today" returns to the live view.
  • iCloud and Exchange calendars via EventKit, with the standard permission flow.
  • Google Calendar via OAuth2 + PKCE; refresh tokens stored in the macOS Keychain.
  • Per-calendar visibility toggles, grouped by source.
  • Four themes — Native, Flexoki, Minimal, Paper — with live preview.
  • Local notifications fired N minutes before each timed event, lead time configurable.
  • Launch at login via SMAppService.mainApp.
Known limitations
  • Read-only. No event creation, no quick-add. Coming in v1.1.
  • Cross-source duplicates. Events that appear in both an EventKit calendar and a connected Google calendar will appear twice. Dedup is on the v1.1 list.
  • Refresh-on-open only. Events refresh when the popover opens — there's no background timer yet.
  • No auto-update. Future versions will need to be downloaded manually. Sparkle is on the roadmap.
